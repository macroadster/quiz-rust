# Category 2: Type System & Generics

20 problems testing advanced knowledge of Rust's type system.

## Topics Covered

- **Trait object safety** — when you can/can't make a `dyn Trait` (021–023)
- **Orphan rules & coherence** — impl conflicts, blanket impls, newtype pattern (024–026)
- **Associated types vs generics** — behavioral differences (027–029)
- **Higher-Ranked Trait Bounds** — `for<'a>` syntax in practice (030–032)
- **GATs (Generic Associated Types)** — lending iterators, implied bounds (033–035)
- **Auto traits** — Send, Sync, Unpin propagation rules (036–037)
- **Deref coercion & method resolution** — surprising dispatch chains (038)
- **Turbofish & type inference** — edge cases (039)
- **Const generics** — limitations and gotchas (040)
