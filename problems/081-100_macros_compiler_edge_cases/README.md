20 problems testing knowledge of macros, compiler behavior, and tricky edge cases.

- **Procedural macros** — derive behavior, token stream subtleties (084–086)

- **Method resolution & autoref/autoderef** — surprising dispatch (090–092)
- **Pattern matching edge cases** — binding modes, match ergonomics (093–095)
- **Const evaluation** — const fn limitations, const panics (096–097)
- **Never type (!)** — coercion rules (098)
- **Operator overloading** — ownership in operators (099)
- **The Ultimate Quiz** — combining multiple subtle features (100)
